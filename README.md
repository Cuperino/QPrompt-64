# QPrompt 64
QPrompt 64 is a reinterpretation of the QPrompt Teleprompter App, adapted to work on the Commodore 64. It was made as part of an April Fools joke. However, the software is real and fully functional.

## Releases
- [v1.0 - Stable](http://c64.qprompt.app/1.0) ([Download](https://c64.qprompt.app/1.0/qprompt64-stable.prg)) Runs on both NTSC and PAL Commodore 64's
- [v1.1b - Color](http://c64.qprompt.app/1.1b) ([Download](https://c64.qprompt.app/1.1b/qprompt64-color.prg)) Introduces color text but runs only on PAL stock Commodore 64's. It can work on NTSC by overclocking.

This software was tested to work on the Commodore 64 Ultimate and the VICE emulator.

## April Fools
QPrompt 64 was made as part of an April Fools joke, in which QPrompt's author discovered the app by establishing an HTTP connection over a quantum tunnel to a parallel dimension and, possibly, a different time period.

QPrompt 64’s discovery announcement can be found at the QPrompt’s blog: https://www.patreon.com/posts/153610642/ 

The tunneled website can be accessed from http://c64.qprompt.app/. The website aims to be period accurate to the year 1996. It was made using the same web development techniques used to create mortised sites throughout the 90s and early 2000s. It was mostly made using Microsoft FrontPage 5, works on a display resolution of at least 640x480 and is known to work on the Netscape Navigator 4 web browser. It also scales-up to modern displays, tho navigating it from a phone is inconvenient.

An alternate URL to access this site is: http://teleprompterforcommodore64terminals.com
It makes a reference to a previous April Fools joke from the same author, done a year prior to QPrompt’s existence being released, where he announced Teleprompter for Terminals, in response to people who were asking for a teleprompter app lighter than Imaginary Teleprompter, which he also co-created.
